### Gate M1 — MVP (17/01/2027)
- Customer register/login/refresh/logout; xem, tìm kiếm, lọc products.
- Cart thao tác theo user, persist Redis; checkout tạo order với snapshot giá.
- Trừ tồn kho an toàn hoặc cơ chế nhất quán rõ ràng; thanh toán giả lập; order state machine.
- UI hiển thị kết quả, lịch sử đơn; API lỗi và idempotency được test.
- E2E thành công/không đủ hàng/thanh toán lỗi/retry/403 đều có bằng chứng test.

### Gate M2 — Beta (28/02/2027)
- User/Role/Permission Management có tests; đảm bảo xử lý JWT stale permission.
- Product reviews + UI; Kafka order events + notification consumer.
- Local Kafka 3-node KRaft (replication/ISR); log pipeline Filebeat → Kafka → Logstash → Elasticsearch → Kibana (độ bền và retry được test).
- Runbook dựng stack, kiểm thử broker/worker down, hướng dẫn vận hành/khôi phục.

### Quy tắc phạm vi
- Không đưa Seller, Promotions, Elasticsearch Search, Kubernetes production vào MVP mặc định.
- S1 kiểm tra các module đã có (User, Product, Gateway, RBAC, FE). Đừng suy luận **Done** chỉ vì có class.
- Nếu một epic >32 giờ: tách scope hoặc kéo qua sprint kế; không bỏ test để giữ ngày.
- Vòng review mỗi Chủ nhật; re-estimate dựa trên velocity thực tế sau S1–S2.

`Baseline → Cart → Order/Inventory → Payment/Checkout → MVP E2E → RBAC management → Kafka/Review → Kafka cluster/ELK`.
